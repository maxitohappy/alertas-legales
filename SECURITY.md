# Política de seguridad

Si encuentra una vulnerabilidad, **no abra un issue público**. Use la opción
*Security → Report a vulnerability* (aviso privado de GitHub) de este repositorio.
Responderemos en un plazo máximo de 5 días hábiles.

El análisis completo de amenazas y controles está en [docs/seguridad.md](docs/seguridad.md).
